# Project Requirements

## Project
Automated Prescription Management System

## Purpose

A healthcare information system designed to streamline prescription management for physicians, patients, and pharmacies.

## Core Features

- Physician dashboard
- Patient profile management
- Prescription creation
- Prescription validation
- Prescription history
- Pharmacy management
- Prescription transmission
- Refill requests
- Notifications
- Error handling

## Main Users

- Physician
- Patient
- Pharmacist

In Development
