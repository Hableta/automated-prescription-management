# Automated Prescription Management System

## Overview

A healthcare information system designed to streamline prescription management for physicians, patients, and pharmacies.

The system supports prescription creation, validation, prescription history, pharmacy selection, prescription transmission, notifications, and refill requests.

## Project Objectives

- Improve prescription management workflows
- Reduce errors caused by missing prescription information
- Provide structured prescription records
- Support communication between physicians, patients, and pharmacies
- Provide a clear workflow for prescription refills

## Key Features

- Physician dashboard
- Patient profile management
- Prescription creation and validation
- Prescription history
- Pharmacy management
- Prescription transmission
- Refill requests
- Notifications and error handling

## Planned Technology Stack

- Java
- Spring Boot
- PostgreSQL
- React
- REST APIs
- GitHub
